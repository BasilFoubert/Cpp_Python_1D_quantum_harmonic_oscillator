A function to evaluate Hermite polynomials

this function evaluates Hermite polynomials H_i with i ranging from 0 to n over a range of values specified by the user and stores the range in the range attribute and the results in the values attribute

Parameters
xThe range of values you wish to evaluate Hermite polynomials over, specified as a row vector
nThe function evaluates n+1 polynomials, from H_0 to H_n

values is stored as a matrix with n+1 rows with the same size (i.e. same number of columns) as the input vector x : row i is H_i evaluated at every point of the vector x, for all 0 <= i <= n
