A function to compute solutions of the 1D-HO Schrödinger equation

this function computes all of the solutions psi_i with i ranging from 0 to n over an interval

Parameters
nThe function computes n+1 solutions, from psi_0 to psi_n, n must be greater or equal ot zero
infThe lower bound of the interval you wish to compute the solutions over
supThe upper bound of the interval you wish to compute the solutions over
n_pointsThe number of points on the interval you wish to compute the solutions over (evenly spaced points), must be greater or equal to 2
Returns
A matrix with n+2 rows and n_points columns : row 0 is the interval, rows 1 to n+1 are the values of psi_0, ..., psi_n over this interval

void Psi_compute::eval ( arma::rowvec  x,
unsigned int  n 
)

A function to evaluate 1D-HO solutions of the Schrödinger equation

this function computes all of the solutions psi_i with i ranging from 0 to n over a range of values specified by the user and stores the range in the range attribute and the results in the values attribute

Parameters
xThe range of values you wish to evaluate Hermite polynomials over, specified as a row vector
nThe function evaluates n+1 polynomials, from H_0 to H_n

values is stored as a matrix with n+1 rows with the same size (i.e. same number of columns) as the input vector x : row i is H_i evaluated at every point of the vector x, for all 0 <= i <= n
