A function to evaluate Hermite polynomials

this function evaluates Hermite polynomials H\+\_\+i with i ranging from 0 to n over a range of values specified by the user and stores the range in the range attribute and the results in the values attribute


\begin{DoxyParams}{Parameters}
{\em x} & The range of values you wish to evaluate Hermite polynomials over, specified as a row vector \\
\hline
{\em n} & The function evaluates n+1 polynomials, from H\+\_\+0 to H\+\_\+n\\
\hline
\end{DoxyParams}
